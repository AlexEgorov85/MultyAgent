Тип ответа — перечень пунктов проверки. Сначала одна строка с итогом (сколько пунктов найдено), затем маркированный список: «номер — название (риск, статус, срок)». Сохраняй номера, ID и статусы. Число найденных пунктов уже указано в черновике — не пересчитывай его по количеству строк списка.
