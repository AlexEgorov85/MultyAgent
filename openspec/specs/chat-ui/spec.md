# Chat UI

## Purpose

Предоставляет готовый чат-интерфейс уровня современных ассистентов, связанный с LangGraph API, без Streamlit и без раскрытия серверных секретов.

## Requirements

### Requirement: Готовый интерфейс

Система SHALL использовать `assistant-ui` с runtime `@assistant-ui/react-langgraph`; Streamlit SHALL NOT использоваться.

#### Scenario: Запуск интерфейса

- **WHEN** пользователь выполняет команды из README
- **THEN** открывается чат с историей сообщений и полем ввода
- **AND** интерфейс не является Streamlit-приложением

#### Scenario: Выбор библиотеки не подтверждён

- **WHEN** альтернатива не согласована до установленного срока
- **THEN** используется `assistant-ui` как вариант по умолчанию
- **AND** замена не блокирует backend

### Requirement: Связь с LangGraph API

Система SHALL отправлять сообщения в LangGraph API server и SHALL получать ответы графа.

#### Scenario: Аналитический запрос из чата

- **WHEN** пользователь отправляет вопрос в интерфейсе
- **THEN** frontend вызывает API с сообщением, `thread_id` и `auditor_id`
- **AND** отображает ответ, SQL и evidence, возвращённые графом

#### Scenario: Продолжение диалога

- **WHEN** пользователь задаёт follow-up в той же нити
- **THEN** frontend передаёт тот же `thread_id`
- **AND** ответ учитывает предыдущий контекст

### Requirement: Выдача ответа и ошибки

Система SHALL показывать состояние ожидания во время работы графа и SHALL корректно отображать ошибки. Потоковая выдача текста является опциональным улучшением, а не обязательным требованием.

#### Scenario: Долгий ответ

- **WHEN** граф формирует ответ дольше нескольких секунд
- **THEN** интерфейс показывает состояние ожидания
- **AND** не выглядит зависшим

#### Scenario: Потоковая выдача (опционально)

- **WHEN** UI переведён на `runs/stream`
- **THEN** первые токены ответа появляются до завершения графа
- **AND** переход не ломает историю и повтор запроса

#### Scenario: Ошибка backend

- **WHEN** API вернул ошибку или соединение потеряно
- **THEN** интерфейс показывает понятное сообщение на русском
- **AND** позволяет повторить запрос

### Requirement: Безопасность секретов

Система SHALL держать ключи LLM и доступ к базе только на backend.

#### Scenario: Проверка frontend bundle

- **WHEN** frontend собирается для production
- **THEN** в bundle отсутствуют LLM-ключи и административные DSN
- **AND** браузер обращается только к разрешённому API

### Requirement: Защита публичной демонстрации

Система SHALL NOT поднимать публичный туннель без пароля, если пользователь явно не отключил защиту.

#### Scenario: Запуск без пароля

- **WHEN** `scripts/share_ui.ps1` запускается без пароля и без `-NoAuth`
- **THEN** скрипт завершается с ошибкой и инструкцией, как задать пароль
- **AND** туннель не поднимается

#### Scenario: Осознанное отключение

- **WHEN** передан `-NoAuth` или `SHARE_AUTH_ENABLED=off`
- **THEN** скрипт печатает предупреждение, что демо открыто без пароля
- **AND** пароль из `.share-auth.json` имеет приоритет над флагом

### Requirement: Русский интерфейс

Система SHALL отображать подписи, ошибки и системные сообщения на русском языке.

#### Scenario: Системное сообщение

- **WHEN** интерфейс показывает приветствие, ошибку или статус
- **THEN** текст на русском
- **AND** технические идентификаторы не выдаются за пользовательские подписи

### Requirement: Воспроизводимый запуск

Система SHALL фиксировать версии Node.js и npm-зависимостей и SHALL описывать запуск двух процессов.

#### Scenario: Чистая установка

- **WHEN** разработчик выполняет инструкции README на чистой машине
- **THEN** backend и frontend запускаются
- **AND** версии зависимостей совпадают с зафиксированными

#### Scenario: Проверка доступности

- **WHEN** backend запущен
- **THEN** health-check подтверждает доступность API
- **AND** frontend может установить соединение

### Requirement: Совместимость версий

Система SHALL проверить совместимость `@assistant-ui/react-langgraph` и LangGraph API на минимальном тестовом графе до интеграции агентов.

#### Scenario: Несовместимый протокол

- **WHEN** тестовый граф не отвечает ожидаемому runtime
- **THEN** версии фиксируются или заменяются до разработки агентов
- **AND** проблема не переносится на финальную интеграцию
