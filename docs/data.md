# Синтетический набор данных

> Учебный проект. Все данные синтетические (детерминированный seed 42),
> совпадения с реальными организациями и людьми случайны. Не подключайте
> реальные банковские данные и персональную информацию.

Базлайн соответствует спецификациям `data-platform` и `data-generation`
(`openspec/specs/`). Генерация — `scripts/generate_data.py`, загрузка —
`scripts/init_db.py`, проверки — `scripts/qa_checks.py`.

## Состав (baseline seed 42)

- **10 карманов**: 5 тем (ипотека, потребкредитование, платежи, карты,
  вклады) × 2 года (2025, 2026).
- **95 проверок**, **79 актов**, **600 пунктов**, **949 скриптов**,
  **949 запусков**, **2 954 отклонения**.

## Инварианты

- Находки двух типов: `отклонение` (количественное, есть скрипт и
  `rows_found > 0`) и `проблема` (качественная, скрипт может отсутствовать).
- 12–15% пунктов 2026 года — повторные находки со ссылкой на пункт 2025 года.
- У каждого пункта есть `finding_template_key` и `finding_scope`;
  неразличимых дублей внутри акта нет.
- Проверки одного аудитора не пересекаются по датам.
- Расписание, дубли и шаблоны дополнительно проверяет `scripts/qa_checks.py`.

## Ловушки для демонстрации

Набор намеренно содержит краевые случаи:

- отменённая проверка без акта;
- акт на согласовании;
- пункт без скрипта;
- просроченный открытый пункт;
- запуск со статусом `ошибка`;
- трёхуровневый номер пункта (`5.1.1`).

## Языковая политика

Предметные и пользовательские значения в БД — на русском. Технические
идентификаторы (`PKT-2025-MORTGAGE`, `AUD-2026-CARDS-03`), email, SQL и
код скриптов — латиницей и не выдаются за пользовательские подписи.

## Воспроизводимость

```powershell
.venv\Scripts\python.exe scripts\generate_data.py --deviations
.venv\Scripts\python.exe scripts\init_db.py --reset-db --yes --seed
.venv\Scripts\python.exe scripts\build_index.py
.venv\Scripts\python.exe scripts\qa_checks.py
```

`--hash` — офлайн-вариант для тестов: модель индекса сохраняется в БД,
и backend использует те же hash-эмбеддинги для запросов. Для реального
семантического поиска нужен `OPENAI_API_KEY` и индекс без `--hash`.

- temperature 0 у LLM, фиксированный seed 42, фиксированная дата среза
`2026-11-21` (`audit.dataset_metadata`).

## Схема

```text
audit_pockets → audits → acts → act_items → scripts
                                          → script_runs → deviations
knowledge_chunks (pgvector + FTS)   auditor_memory
chat_threads → chat_messages        dataset_metadata
```

Миграции: `db/migrations/001–009`, реестр `public.schema_migrations`.
`init_db.py` поднимает встроенный PostgreSQL 16 через `pgserver`,
применяет миграции и создаёт read-only роль `audit_ro`.

Сгенерированные CSV (`data/seed/`) и кластер PostgreSQL (`data/pg/`)
не коммитятся. Методические документы для RAG — `data/knowledge/`.
