## Подготовка

1. `init_db.py --seed`, `build_index.py`.
2. `langgraph dev`, `npm --prefix ui run dev`.
3. Открыть два сценария заранее, чтобы не ждать LLM.
4. Не показывать `.env` и ключи.
5. Для публичной ссылки заранее задать пароль: без него `share_ui.ps1`
   откажется поднимать туннель (обход — явный `-NoAuth`).
